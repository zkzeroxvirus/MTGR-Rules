# **🎯 DOOM SETUP**

At the beginning of each encounter, the Host receives a number of Doom cards based on player count:

| Players | Doom Cards |
| ----- | ----- |
| 1–2 | 0 |
| 3–4 | 1 |
| 5 | 2 |
| 6 | 3 |

* Doom cards are drawn from the **Doom Pool**  
* Each Doom card is unique unless otherwise specified
