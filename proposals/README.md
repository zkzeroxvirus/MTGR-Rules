# Historical Host design proposals

These documents preserve design discussion from August and September 2026. They are not active gameplay rules or the current playtest specification.

For the current opt-in package, use [Host Commands playtest](../experiments/host-commands-playtest.md): four archetypes, tier choices, and ten Skill Points. Published Host Authority rules remain canonical unless the table selects that package.

| MTGR-HOST-COMMAND-PROGRESSION-AND-SKILL-TREE-DESIGN-V0.2.docx | Six-point progression and proposed Command library. |
| MTGR-HOST-PROFILE-AND-COMMAND-SYSTEM-V0.3.docx | Earlier profile and Command implementation draft. |
| MTGR-HOST-PROFILE-AND-COMMAND-SYSTEM-V0.4.docx | Three-branch, six-point progression architecture. |
| MTGR-HOST-SKILL-TREES-REWORK-V0.3.docx | Four-archetype design source preceding the current tier-choice adaptation. |

Version numbers belong to separate document series; do not compare them as one revision sequence. Mechanics and approval claims in these proposals must be checked against the current playtest and canonical rules before reuse.

Document builders are preserved under `builders/`. They require Python with python-docx; the V0.2 builder also requires Pillow. Outputs are historical proposals and must not be used to regenerate canonical rules.

The older progression branch, including its previously unpushed design-guidance commit, is preserved in the remote tag `archive/host-progression-playtest-2026-10-12`.
