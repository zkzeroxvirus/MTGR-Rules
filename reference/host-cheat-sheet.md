# MTG Roguelike — Host Cheat Sheet

> Quick table reference for running an MTGR session. Use the Full Rules for edge cases and complete subsystem text.

## 1 — Before Encounter 1

1. Finish player deckbuilding.
2. Resolve the starting **Event** first. It cannot be a Bad Stuff Event.
3. Resolve the **Trinket**.
4. Players may use the one-time seat-swap window before Encounter 1 begins.

After Encounter 1 begins, normal Town / Stay Out Event timing applies.

## 2 — Host Encounter Setup

At the beginning of each encounter:

1. Determine Host HP from player count, mode, and encounter number.
2. Determine **Authority Level** from player count.
3. Set up **Doom** cards from player count.
4. Apply **Demonic Persistence** and **Arcane Suppression**.
5. Roll the Affixes required for the encounter.

### Authority Effects

- **I:** First Host spell each turn costs {1} less.
- **II:** Authority I + create **Not Today** at encounter start. Sacrifice it to counter a spell, activated ability, or triggered ability.
- **III:** Authority II + at end of the Host draw step choose: draw an additional card, or play an additional land this turn.
- **IV:** First Host spell costs {1} less; once per encounter cast a copy of **Disallow** for free; play one additional land; draw an additional card each draw step.
- **V:** Authority IV + create **Not Today** at encounter start.

### Always-On Scaling

**Demonic Persistence — Tempo Reclamation:** once each turn, when a Host spell is countered or a Host permanent leaves the battlefield due to an opponent's spell or ability, create a Treasure token.

**Arcane Suppression:** at encounter start choose a player. When another player casts a counterspell, each other player gets an Arcane Suppression counter. Their spells cost {1} more for each counter they have.

### Affix Structure

| Encounter | Standard | Variant |
|---|---|---|
| E1 | Tier 1 | Tier 1 |
| E2 | Tier 1 + Tier 2 | Tier 1 + Tier 2 |
| E3 | Tier 1 + Tier 2 + Tier 3 | Tier 1 + Tier 2 + Tier 3 |
| E4 | — | Tier 1 + Tier 2 + Tier 3 + Tier 4 |

Affixes are rerolled each encounter. If a combination is game-breaking, reroll the highest tier.

Affix bonus XP: **T1 +5 / T2 +10 / T3 +15 / T4 +20**.

|---|---:|---:|

Base XP is per player. Failed encounters grant no XP.

## 3 — Turn / Combat Reminders

- The party shares one Untap, Upkeep, Draw, Main, Combat, and End Step; each player still controls their own cards and permanents.
- All party attackers are declared simultaneously; the Host blocks after the full declaration.
- The Host takes a normal turn.
- The Host chooses attack targets.
- Adjacent players may block for each other when an adjacent ally is attacked.

## 4 — Encounter Result

### Party Wins

Resolve all three rewards immediately after victory: **XP, Cashout, and Loot Pool**. They may be resolved in any order.

After all rewards are resolved, the party chooses **Town or Stay Out**.

### Party Loses

1. Skip XP, Cashout, and Loot Pool.
2. The party still chooses **Town or Stay Out**.
3. Reset all players to full HP before the next encounter.
4. Event resolution continues normally.

Death is not permanent. A dead player returns in future encounters and suffers no XP penalty for dying.

## 5 — Between Encounters

### Town

1. Fully heal all players.
2. Resolve Town building usage.
3. Resolve Event(s).

### Stay Out

1. Gain XP.
2. Gain Mystery Packs.
3. Resolve a Supply Drop.
4. Resolve a Wanderer.
5. Resolve Event(s).
6. Begin the next encounter.

### Event Resolution

1. Draw or roll a random Event.
2. Resolve its immediate instructions.
3. Record any continuing, delayed, Town, next-encounter, or run-long effect.
4. Repeat if multiple Events are required.

The printed Event card controls that Event's specific effect and duration.

## 6 — The Crypt

After the final scheduled encounter, the party faces the Crypt.

- **No Affixes** are applied.
- The **Host takes the first turn**.
- **No Events** are resolved.
